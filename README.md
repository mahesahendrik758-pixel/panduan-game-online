# Panduan Game Online

Dokumentasi sederhana mengenai keamanan akun, keamanan digital,
dan penggunaan platform game online.

## Tentang Repository

Repository ini dibuat sebagai dokumentasi dan referensi ringan
untuk pengguna yang ingin memahami beberapa aspek penting
dalam aktivitas game online.

## Panduan

### Keamanan Akun

Beberapa hal yang perlu diperhatikan:

- Gunakan password yang kuat dan berbeda.
- Jangan membagikan password kepada orang lain.
- Jangan memberikan kode OTP kepada siapa pun.
- Aktifkan autentikasi dua faktor jika tersedia.

### Mengenali Phishing

Periksa alamat website sebelum memasukkan informasi akun.
Hindari tautan mencurigakan yang meminta password, OTP,
atau informasi pribadi.

### Keamanan Perangkat

Pastikan sistem operasi dan browser selalu diperbarui.
Gunakan perangkat lunak keamanan dari sumber terpercaya.
